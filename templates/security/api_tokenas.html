Kaip naudoti

Visose užklausose į /api/v1/* pridėkite antraštę: 

Authorization: Bearer <jūsų tokenas>

Pavyzdys (curl):

curl -H "Authorization: Bearer YOUR_TOKEN" \
     http://127.0.0.1:5000/api/v1/me

Prieinami maršrutai:

  • POST /api/v1/auth/token — prisijungimas
  • POST /api/v1/auth/logout — atsijungimas
  • GET  /api/v1/me — mano info
  • GET  /api/v1/children — mano vaikai (tėvams)
  • GET  /api/v1/children/<id> — vaiko duomenys
  • GET  /api/v1/announcements — skelbimai
  • GET  /api/v1/contacts — kontaktai
  • GET  /api/v1/health — būsenos patikra (be autentikacijos)
